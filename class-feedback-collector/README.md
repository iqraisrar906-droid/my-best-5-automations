# Class Feedback Collector

## Description
This automation collects student feedback using Google Forms, stores responses in Google Sheets, and uses Gemini AI to summarize feedback.

## Tools Used
- Google Forms
- Google Sheets
- Gemini AI
- Google Apps Script

## How to Run
1. Open the Google Form.
2. Submit feedback.
3. Check the responses in Google Sheets.
4. Use Gemini AI to summarize the feedback.
